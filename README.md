# Kastrula Games

Браузерная аркада: 19 классических игр в одном месте — с неоновым меню в стиле синтвейв, живыми превью игр на карточках, музыкой и рекордами. Всё написано на чистом HTML, CSS и JavaScript, без библиотек и сборки.

**Играть:** `https://<твой-ник>.github.io/<название-репозитория>/`

## Возможности

- Меню с живыми превью: игры сами играют на карточках, при наведении превью оживает.
- Окно «Подробнее» для каждой игры: как играть, рекорд и управление.
- Интро, музыка меню и фон, который пульсирует в такт басу, спектроанализатор на горизонте.
- Звуки во всех играх синтезируются прямо в браузере (Web Audio API).
- Рекорды сохраняются в браузере (`localStorage`).
- Управление с клавиатуры, мышью и касаниями; на телефоне появляются экранные кнопки.

### Общие клавиши в игре

| Клавиша | Действие |
| --- | --- |
| P / Esc | Пауза |
| R | Начать заново |
| M | Включить / выключить звук |
| Esc на заставке | Вернуться в меню |

## Запуск на компьютере

Просто открой `index.html` в браузере — всё работает без сервера.

Если хочется запустить как на сайте, подойдёт любой локальный сервер, например:

```bash
python -m http.server 8000
```

и затем открой `http://localhost:8000`.

## Публикация на GitHub Pages

1. Создай репозиторий на GitHub и загрузи в него все файлы этой папки (так, чтобы `index.html` лежал в корне).
2. В репозитории открой **Settings → Pages**.
3. В разделе **Build and deployment** выбери **Source: Deploy from a branch**, ветку **main** и папку **/ (root)**, нажми **Save**.
4. Через минуту-две сайт появится по адресу `https://<твой-ник>.github.io/<название-репозитория>/`.

## Структура

```

  controls.js         отрисовка клавиш управления
  icons.js            SVG-иконки интерфейса
  menu.js             меню и окно «Подробнее»

  intro.js            интро, музыка меню, фон в такт басу

assets/
```

## Как добавить свою игру

1. Добавь запись в `js/games.js` (id, название, описание, `how`, `keys`).
2. Создай `games/<id>.js` и зарегистрируй игру:

```js
Arcade.register({
  width: 480,
  height: 480,
  start(api) { /* начальное состояние */ },
  update(dt, api) { /* логика; api.pressed('left'), api.addScore(10), api.gameOver() */ },
  draw(ctx, api) { /* отрисовка на canvas */ },
});
```

Игра автоматически появится в меню вместе с живым превью.

## Заметки

- Браузеры не разрешают сайтам включать звук до первого действия пользователя, поэтому музыка меню может начать играть только после первого клика или нажатия клавиши.
- Пиксельный шрифт Press Start 2P и шрифт Rubik подключаются из Google Fonts; без интернета будут использованы системные шрифты.
